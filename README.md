📌 **Devote - To-Do List App**

An easy-to-use and feature-packed to-do list app designed to help you stay organized, with added customization options like themes and haptic feedback!

🌟 Highlights

- To-Do List: Manage and organize your tasks effortlessly.
- Dark & Light Theme: Switch between a dark or light theme for a personalized look.
- Widget: Access your tasks directly from your home screen with a handy widget.
- Get subtle haptic feedback on certain actions for a more interactive experience.

🚀 Usage

Create tasks: Add new tasks by tapping the "+" button.
Mark tasks complete: Check off tasks as you complete them.
Delete tasks: Swipe left on any task to remove it.
Change themes: Switch between dark and light mode using the moon button.
Use the widget: Add the Devote widget to your home screen to quickly view and manage tasks.

⬇️ Installation

Clone the repository to your local machine:
git clone https://github.com/Nastasyaya/Devote
Open the project in Xcode.
Run it on a simulator or physical device.
